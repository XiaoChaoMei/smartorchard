# ESP32 智慧果园环境监测与自动灌溉系统

基于 ESP32 + MicroPython 的果园环境监测、自动灌溉和驱鸟目标检测工程。
设备采集土壤湿度、空气温湿度、气体、光照、人体、火焰、降雨、雷达和
超声波数据，通过 Wi-Fi 连接巴法云 MQTT，与微信小程序联动；同时支持
手机网页配网和本地执行器控制。

这是可以实际烧录运行的演示工程。传感器阈值属于原型参数，未完成现场
标定，不能作为专业农业或安全测量设备使用。

## 当前工程包含

- 土壤湿度传感器：湿度百分比估算，驱动自动灌溉。
- DHT11：空气温度和湿度。
- MQ-2：可燃气体/烟雾模拟量，当前上传 ADC 原始值。
- 雨滴传感器：开机干燥校准，输出降雨量和雨型。
- PIR：人体红外，配合光照实现夜间补光。
- 火焰传感器：检测到火焰时蜂鸣器报警。
- 光敏电阻：相对光照百分比，用于补光判定。
- RCWL-0516 雷达 + HC-SR04 超声波：移动检测和距离二次确认。
- 水泵继电器、有源蜂鸣器、LED 补光灯：本地执行器。
- 巴法云 MQTT：数据上报、远程水泵控制和自动浇水阈值设置。
- Wi-Fi 自动配网：连接失败时开启热点和手机网页配置页面。

## 接线

| 模块 | 模块引脚 | ESP32 | 说明 |
|---|---|---|---|
| 土壤湿度传感器 | AO | GPIO34 | ADC 输入，只读引脚 |
| DHT11 | DATA | GPIO13 | 3.3V 供电，模块自带上拉 |
| MQ-2 | AO | GPIO35 | ADC 输入，输出不得超过 3.3V |
| 雨滴传感器 | AO | GPIO36 | ADC 输入，开机时保持干燥 |
| PIR | OUT | GPIO22 | 数字输入 |
| 火焰传感器 | DO | GPIO23 | 低电平触发 |
| 光敏电阻模块 | AO | GPIO32 | ADC 输入 |
| RCWL-0516 | OUT | GPIO27 | VIN 接 5V，OUT 为 3.3V 逻辑 |
| HC-SR04 | TRIG | GPIO25 | 3.3V 触发 |
| HC-SR04 | ECHO | GPIO26 | 5V 输出，必须分压到 3.3V |
| 水泵继电器 | IN | GPIO5 | 高电平开泵，需确认继电器模块电平 |
| 有源蜂鸣器 | I/O | GPIO19 | 低电平响 |
| LED 补光灯 | 控制端 | GPIO2 | 大功率灯需经三极管/MOSFET 驱动 |

HC-SR04 的 ECHO 是 5V 输出，推荐分压：

```text
HC-SR04 ECHO -- 1kΩ --+-- GPIO26
                       |
                      2kΩ
                       |
                      GND
```

ESP32 的 GPIO34~GPIO39 只能作为输入，不能驱动执行器。水泵、LED 和
蜂鸣器一律由 GPIO 控制逻辑电平，负载电源单独供电并共地。

## 控制规则

自动灌溉：

1. 土壤湿度低于启动阈值（默认 55%）时开泵。
2. 土壤湿度高于停止阈值（85%）时关泵。
3. 位于两者之间时保持水泵当前状态，避免频繁启停。

远程控制：

1. 主题 `P004` 收到 `on`：切到手动模式并开泵。
2. 主题 `P004` 收到 `off`：切到手动模式并关泵。
3. 主题 `M004` 收到 `auto`：恢复自动控制。
4. 主题 `M004` 收到 `manual`：切到手动控制。
5. 主题 `ST004` 收到数值：修改自动浇水启动阈值，范围 30~80。

本地联动：

- 检测到火焰：蜂鸣器响；火焰消失后停止。
- 检测到人员且光照低于 30%：LED 打开。
- 检测到人员且光照高于 40%：LED 关闭（30%~40% 为回差区间）。
- 未检测到人员：LED 关闭。
- 降雨只上报，不强制关闭水泵。
- MQ-2 超过 800 只上报“超标”，不联动执行器。

驱鸟判定：

- RCWL-0516 检测到移动后，才读取 HC-SR04 距离。
- 距离 ≤100cm 连续 2 次，判定为有效目标。
- 连续 2 次不满足条件后解除目标状态。
- HC-SR04 只负责测距，不是驱鸟执行器；真正驱鸟需要另加超声波
  发射器并由 MOSFET/继电器控制。

## 巴法云 MQTT

设备使用巴法云 MQTT（`bemfa.com:9501`）连接，凭据从 `config.py` 读取。
MQTT 断开后主循环会自动重连。

| 主题 | 方向 | 内容 |
|---|---|---|
| `GM004` | 上报 | `光照强度：xx%` |
| `Q004` | 上报 | `气体浓度：原始值，状态：正常/超标` |
| `H004` | 上报 | `检测到火焰` / `无火焰` |
| `R004` | 上报 | `检测到人员` / `无人员` |
| `Y004` | 上报 | `降雨量：xx%，雨型：xx，状态：...` |
| `W004` | 上报 | `温度：xx℃，湿度：xx%` |
| `T004` | 上报 | `土壤湿度：xx%，水泵：运行中/已停止，模式：自动/手动` |
| `P004` | 订阅 | `on` / `off` |
| `M004` | 订阅 | `auto` / `manual` |
| `ST004` | 订阅 | 自动浇水启动阈值，30~80 |
| `LD004` | 上报 | 雷达状态，`1` 检测到移动，`0` 无移动 |
| `CSB004` | 上报 | 超声波距离（cm），`-1` 表示本次无有效测距 |

主题名可在 `config.py` 中修改，需与微信小程序和巴法云控制台保持一致。

## Wi-Fi 自动配网

1. 启动时优先读取 `net/wifi_config.json`，没有则使用 `config.py` 的值。
2. 连接路由器最多等待约 20 秒。
3. 连接失败时开启热点，热点名称和密码由 `config.py` 的
   `AP_SSID`、`AP_PASSWORD` 决定。
4. 手机连接热点后访问 `http://192.168.10.1`。
5. 提交路由器 Wi-Fi 名称和密码后，配置写入 `net/wifi_config.json`，
   ESP32 自动重启。
6. 重启后仍连接失败，会再次进入配网模式。

`net/wifi_config.json` 含有 Wi-Fi 明文密码，已加入 `.gitignore`。
配网热点只是临时通道，请把 `AP_PASSWORD` 改成至少 8 位的强密码。

## 编译与烧录

设备需要先烧录带 `umqtt.simple` 的 MicroPython 固件。复制以下文件到
ESP32 文件系统（以 `COM3` 为例）：

```powershell
mpremote connect COM3 fs cp main.py :
mpremote connect COM3 fs cp config.py :
mpremote connect COM3 fs cp -r sensors :
mpremote connect COM3 fs cp -r actuators :
mpremote connect COM3 fs cp -r net :
mpremote reset
```

也可以使用 Thonny 手动上传，上传后确保设备根目录存在 `main.py`、
`config.py` 以及 `sensors/`、`actuators/`、`net/` 三个目录。

执行器单独测试：把 `config.py` 中的 `ACTUATOR_TEST_MODE` 改为 `True`，
启动后会依次测试 LED、蜂鸣器和水泵各 2 秒。测试完成后必须改回
`False`，否则每次上电都会动作水泵。

## 预期结果

1. 串口显示系统启动、控制规则和雨滴传感器校准信息。
2. 能连接路由器并显示分配到的 IP 地址。
3. MQTT 连接成功后订阅 `P004`、`M004`、`ST004`。
4. 手机小程序能看到全部传感器数据和设备在线状态。
5. 土壤湿度低于阈值时水泵自动启动，高于 85% 时自动停止。
6. 小程序下发 `on`/`off`/`auto` 能切换水泵状态和模式。
7. 检测到火焰时蜂鸣器响，检测到人员且光照不足时 LED 亮。
8. 雷达检测到移动后上报距离，连续确认后输出驱鸟目标状态。

## 安全边界

- `config.py` 和 `net/wifi_config.json` 含真实凭据，禁止提交或截图公开。
- 水泵必须由独立电源和继电器/MOSFET 驱动，GPIO 不能直接带负载。
- 继电器是否高电平有效取决于模块型号，接水泵前先用万用表确认。
- HC-SR04 ECHO 不能直接接 ESP32，必须分压或电平转换。
- MQ-2 上传的是 ADC 原始值，不是标定后的 ppm。
- 光敏电阻输出是相对百分比，不是 lux。
- 雨滴传感器必须干燥开机，否则会得到错误的干湿基准。
- MQ-2、土壤和光照阈值均为演示值，实际部署前需要现场标定。
- 当前工程未实现掉电保存自动浇水阈值，重启后恢复为 `config.py` 的值。
